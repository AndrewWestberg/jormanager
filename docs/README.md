# Welcome

JorManager is opinionated Cardano Stakepool management software. By opinionated, we mean that it will guide you down a certain path for how you create, manage, and maintain your stakepool.

If you are going for the most secure way to run a stakepool, it isn't that. If you are going for the most flexible way to run a stakepool, it isn't that. What JorManager aims to be is the most operator-friendly way to run a stakepool.

There are places where we intentionally trade a bit lower security for more ease of use. There are places where operating a pool allows you multiple ways of configuring things. JorManager may choose to only offer one good and default option.
